# Hero-Grafik Vorschläge

Diese Dateien sind reine Konzeptdateien und nicht in die Website eingebunden.

## Zweck

Der Ordner zeigt neun alternative, animierte Richtungen für das erste visuelle
Element der Startseite:

- `Engineering Control Board`
- `Reliability Evidence Map`
- `Real Work + Method Overlay`
- `Reliability Workbench`
- `Failure Lifecycle Animation`
- `Life Data & Weibull Fit`
- `DoE Factor Space`
- `Risk-to-Evidence Pipeline`
- `Health Monitoring & Prognostics`

Die Konzepte sollen helfen, eine Richtung zu bewerten, bevor Code in der
eigentlichen Website geändert wird.

Die Vorschläge 5 bis 9 sind stärker fachlich ausgerichtet und visualisieren
typische Zuverlässigkeitsprobleme beziehungsweise RelTest-Leistungsfelder wie
Lebensdauerverhalten, Weibull-Auswertung, DoE, Risikomanagement und Prognostik.

## Öffnen

Die Vorschläge können direkt im Browser geöffnet werden:

```txt
concepts/hero-grafik-vorschlaege/index.html
```

## Entfernen

Wenn die Vorschläge nicht mehr benötigt werden, kann der komplette Ordner
gelöscht werden. Die produktive Website nutzt diese Dateien nicht.
